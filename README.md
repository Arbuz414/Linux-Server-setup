# Linux-VPS-setup
Развёртывание и базовая защита Linux VPS

# Окружение:
Ubuntu/Debian
Nginx
SSH
UFW
SSL/TLS
DNS

# Что сделал:
настроил SSH-доступ по ключам;
запретил удалённый root login;
настроил firewall UFW;
настроил Nginx;
подключил SSL-сертификат;
настроил DNS;
настроил резервное копирование;
настроил контроль свободного места.

# Результат:
Получился рабочий Linux-сервер с веб-сервисом, HTTPS и базовой защитой SSH.
